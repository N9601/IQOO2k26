How the proof works

1. Guided capture

A step-driven overlay walks the buyer through seal check, opening, item reveal and label capture. Object detection and OCR run in the browser, on the device. No skippable steps.

2. Chain of custody

Each frame is hashed into a chain: SHA-256(frame, wall clock, monotonic clock, previous hash). A Merkle root over all links is signed with a non-extractable ECDSA P-256 key.

3. Independent verification

The manifest is a few kilobytes of JSON that anyone can verify offline. Change one byte, anywhere, and the signature check fails. Try it on the Verify page.
